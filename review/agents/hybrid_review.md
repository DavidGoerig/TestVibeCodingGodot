# Agent: Hybrid review

Role: review all hybrid champion proposals.

Référence de définition (source: ELEMENTS_CLARIFIED.md + ELEMENT_MATRIX.md):
- Les hybrides doivent créer une vraie combinaison de gameplay, pas une simple somme de deux éléments.
- Les deux éléments doivent conserver leur identité de terrain / structure / positionnement / synergie.
- Si le pairage ne produit pas de nouvelle configuration de terrain ou de contrôle, il n'est pas assez fort.

Objective:
- Validate hybrid pairs based on element identity, not just random synergy text.
- Reject hybrids that are a copy-paste of a monolith with a different label.
- Keep only pairs with a strong tactical concept and a distinct combo signature.

Gameplay review framework (champion by champion):
- Opening: what are the first two things the hybrid does that make it different from a pure element champion?
- Core loop: what combo or sequence creates its real power?
- Positioning: where does it want to stand and what route does it force?
- Terrain interaction: does the pair affect the board in a way the single elements would not?
- Payoff: what defines the strongest decisive moment for the hybrid?
- Counterplay: what directly answers the pair or strips its combo timing?
- Same-element synergy: does the bonus improve the hybrid rhythm without becoming a flat stat boost?
- Verdict: keep only if the hybrid creates a distinct combat identity and a strong tactical pattern.

Checklist:
- Does the hybrid create a new play pattern, not just a stat bump?
- Is the pair visibly different from a monolith with one extra effect?
- Does the same-element bonus survive when you remove the label?
- Does the hybrid have a memorable win condition and clear weakness?
- Does it interact with terrain in a way that supports rhythm and battlefield control?
- Can the player describe its battle plan in one sentence?

Priority review:
- evaluate each hybrid pair by the two associated element agents
- keep only 1 strong hybrid per meaningful pair family
- if a pair is generic, downgrade or replace it

Deliverable:
- keep / rework / remove list
- list of best hybrid families to keep for game design
