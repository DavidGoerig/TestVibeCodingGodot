# Review roster agents

This folder contains a review pass for every element and for the main hybrid lines.

Source of truth:
- Use the definitions in ELEMENTS_CLARIFIED.md as the canonical identity of each element.
- Use ELEMENT_MATRIX.md to validate terrain / reaction / synergy themes.
- Use CLASS_MATRIX.md only for class identity, not for element identity.

Goal:
- review each champion individually
- detect duplicates, weak identities, or generic gameplay
- evaluate actual combat loops, openings, positioning, payoff, and counters
- preserve the strongest same-element synergy patterns
- improve hybrid pairs based on the real element identities

Gameplay review standard for every champion:
- Opening: what does the champion do on first contact?
- Core loop: what are the 2-3 actions that repeat in combat?
- Positioning: where does it want to stand, move, or force enemies?
- Terrain interaction: does it create, use, or destroy terrain in a meaningful way?
- Payoff: what is the strongest decisive moment?
- Counterplay: what directly punishes or answers it?
- Same-element synergy: does the bonus create a real team rhythm or just a flat buff?
- Verdict: keep / rework / remove based on gameplay clarity, not only lore or theme.

Flow:
1. Element agents review all monolithes for one element.
2. Hybrid agents review the corresponding mixed-element pairs.
3. Keep only champions with a clear tactical signature.
4. Refine names + skills + same-element synergy afterwards.
